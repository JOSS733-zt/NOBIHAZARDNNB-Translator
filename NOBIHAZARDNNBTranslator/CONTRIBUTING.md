# 贡献指南

感谢愿意帮忙！这个项目主要需要的贡献是**翻译库词条**和**问题反馈**。

## 提交问题（Issue）

请尽量带上这些信息，能大幅加快定位：

1. 游戏引擎与版本（MV / MZ / XP / VX / VX Ace）
2. 出问题的步骤（扫描 / 翻译 / 写回 / 还原）
3. 底部日志的报错文字（截图或复制）
4. `%APPDATA%\NNB-Translation\crash.log`（如果存在）

⚠️ 不要上传游戏本体或完整数据文件；只贴必要的片段。

## 贡献翻译库词条

词库格式是「原文<TAB>译文」，每行一条：

```
勇者	勇者
セーブしますか？	要保存吗？
```

- 用 UTF-8 编码保存
- 文件名随意，扩展名用 `.tsv` 或 `.txt`
- 可以按作品/题材分文件，例如 `dq_ja_zh.tsv`、`ff_ja_zh.tsv`

提交方式：开 Issue 附上文件，或直接提 PR 放到 `lib/` 目录。

## 提 PR 的约定

- 只改必要的地方，一次 PR 解决一件事
- 代码是 C# 5 语法（用 .NET Framework 4.x 的 `csc.exe` 编译），**不要用 C# 6+ 语法**
- 提交前本地跑一遍测试：`powershell -ExecutionPolicy Bypass -File build.ps1 -Test`
- 界面文案改动需要同步 `src/I18n.cs` 的 6 语言表

## 编译

见 [README 的编译说明](README.md#编译)（需要 .NET Framework 4.x 自带的 `csc.exe`，无需安装 SDK）。

## 行为准则

- 只讨论技术与内容，不涉及政治、地域与人身攻击
- 不提交盗版资源、破解补丁或商业游戏的完整数据
