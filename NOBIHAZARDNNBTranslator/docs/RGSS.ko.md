# XP / VX / VX Ace 안내

## MV/MZ 와의 차이

- 비교 플러그인이 없습니다. **데이터 직접 적용만 지원**
- 데이터 형식은 Ruby Marshal: `.rxdata` / `.rvdata` / `.rvdata2`
- 백업 위치: `translate\backup_<시각>\Data\`

## 세 단계

1. `Data` 가 있는 폴더 선택 → **게임 인식**
2. **텍스트 스캔** → **번역 시작**
3. **게임에 적용**: 먼저 백업하고 파일별로 적용하며, 마지막에 다시 파싱해 검증

## 번역 대상

이벤트 대사·선택지·스크롤 텍스트·이벤트 이름·맵 이름·액터(이름/별명/설명)·클래스·아이템·무기·방어구·스킬·상태·적·공통 이벤트·적 그룹·시스템 용어와 메시지.

## 주의

- **중국어가 □로 보임**: `Fonts\` 의 폰트에 중국어 글리프가 없음. 중국어 폰트로 교체
- **0건만 스캔됨**: 텍스트가 RGSS 스크립트 안에 있거나 `Game.rgss3a` / `.rgss2a` / `.rgssad` 로 패킹됨(먼저 압축 해제)
- **적용 후 오류**: **백업 복원** 후 오류 내용을 보내 주세요
- 적용은 문자열과 길이 접두사만 바꾸고 나머지 바이트는 그대로 둡니다
