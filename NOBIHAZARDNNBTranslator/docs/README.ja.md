# Nobihazard NNB-Translation 使い方

作者：JOSS ｜ 単一 exe ｜ インストール不要

## 対応エンジン

| エンジン | データ | 方法 |
|---|---|---|
| RPG Maker MV / MZ | `data\*.json` | 書き戻し、または対照プラグイン導入 |
| RPG Maker XP | `Data\*.rxdata` | 直接書き戻し |
| RPG Maker VX | `Data\*.rvdata` | 直接書き戻し |
| RPG Maker VX Ace | `Data\*.rvdata2` | 直接書き戻し |

2000 / 2003（`.ldb`）は未対応です。

## 3 ステップ

1. **① ゲームを選択**：`www` / `data` / `Data` を含むフォルダを選び、「ゲームを判定」
2. **② 翻訳設定**：エンジンを選び、「エンジン確認」→ **③ 区分をチェック**
3. 「テキスト抽出」→「翻訳開始」→「ゲームに書き戻す」（先に自動バックアップ）

## 翻訳エンジン（すべてキー不要）

| エンジン | 説明 |
|---|---|
| Microsoft（既定） | `cn.bing.com`、中国本土から直結；制限されたら並列数を 1 に |
| MyMemory | 中国本土から直結、1 日約 5000 文字；`[[0]]` を最も保持 |
| Google 無料 API | 中国本土ではプロキシが必要 |

## 区分

チェックした区分だけを抽出・翻訳します：マップイベント / マップ名 / コモンイベント / アイテム / スキル / 武器 / 防具 / アクター / 状態・敵 / 敵グループ / システム / その他。

チェックを外した行は表から隠れ、翻訳もされません。

## ファイルの場所

```
<ゲームフォルダ>
├── translate\cache_<言語>.json   再開用キャッシュ
├── translate\glossary.txt        独自の用語
├── translate\対照表_*.html       原文／訳文の対照表
└── translate\backup_*\           書き戻し前のバックアップ
```

MV/MZ は更に `data\TranslatePlus\` と `js\plugins\TranslatePlus.js` を使用します。

## よくある質問

- **起動直後に落ちる**：exe と同じフォルダの `startup.log` / `crash.log` を確認
- **判定できない**：`data` / `Data` を含む階層を選ぶ。`Game.rgss3a` は先に展開
- **「空の応答」**：制限中。並列数を 1 にして数分待つ
- **状態が「要確認」**：制御コードが欠落。訳文セルを直接修正
- **中国語が□になる**（XP/VX/VA）：`Fonts\` のフォントを変更
- **名前・言語の変更**：`nnb.ini` の `name=` / `lang=`
