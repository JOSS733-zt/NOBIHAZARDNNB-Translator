# XP / VX / VX Ace 說明

## 和 MV/MZ 的差別

- 沒有執行時對照外掛，**只能寫回資料檔**
- 資料格式是 Ruby Marshal：`.rxdata` / `.rvdata` / `.rvdata2`
- 備份在 `translate\backup_時間戳\Data\`

## 三步

1. 選到含 `Data` 的那一層 → 「識別遊戲」
2. 「掃描文字」→「開始翻譯」
3. 「寫回遊戲」：先備份，再逐檔寫回，寫完自動重新解析自檢

## 能翻

事件對話 / 選項 / 捲動文字 / 事件名 / 地圖名 / 角色（名字·暱稱·說明）/ 職業 / 物品 / 武器 / 防具 / 技能 / 狀態 / 敵人 / 公共事件 / 敵群 / 系統選單與提示。

## 注意

- **中文顯示方塊**：遊戲 `Fonts\` 字體沒有中文字形，換一個中文字體
- **掃描 0 條**：文字寫在 RGSS 腳本裡，或資料被打包成 `Game.rgss3a` / `.rgss2a` / `.rgssad`（需先解包）
- **寫回後報錯**：先「還原備份」，再把錯誤訊息發我
- 寫回只改字串和長度前綴，其它位元組原樣保留
