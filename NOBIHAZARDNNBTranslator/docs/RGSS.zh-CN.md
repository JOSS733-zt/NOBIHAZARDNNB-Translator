# XP / VX / VX Ace 说明

## 和 MV/MZ 的区别

- 没有运行时对照插件，**只能写回数据文件**
- 数据格式是 Ruby Marshal：`.rxdata` / `.rvdata` / `.rvdata2`
- 备份在 `translate\backup_时间戳\Data\`

## 三步

1. 选到含 `Data` 的那一层 → 「识别游戏」
2. 「扫描文本」→「开始翻译」
3. 「写回游戏」：先备份，再逐文件写回，写完自动重新解析自检

## 能翻

事件对话 / 选项 / 滚动文本 / 事件名 / 地图名 / 角色（名字·昵称·说明）/ 职业 / 物品 / 武器 / 防具 / 技能 / 状态 / 敌人 / 公共事件 / 敌群 / 系统菜单与提示。

## 注意

- **中文显示方块**：游戏 `Fonts\` 字体没有中文字形，换一个中文字体
- **扫描 0 条**：文本写在 RGSS 脚本里，或数据被打包成 `Game.rgss3a` / `.rgss2a` / `.rgssad`（需先解包）
- **写回后报错**：先「还原备份」，再把报错发我
- 写回只改字符串和长度前缀，其它字节原样保留
