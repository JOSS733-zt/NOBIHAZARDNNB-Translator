# XP / VX / VX Ace の使い方

## MV/MZ との違い

- 対照プラグインはありません。**データへの直接書き戻しのみ**
- データ形式は Ruby Marshal：`.rxdata` / `.rvdata` / `.rvdata2`
- バックアップ先は `translate\backup_<日時>\Data\`

## 3 ステップ

1. `Data` を含むフォルダを選ぶ →「ゲームを判定」
2.「テキスト抽出」→「翻訳開始」
3.「ゲームに書き戻す」：先にバックアップし、1 ファイルずつ書き戻し、最後に再解析で検証

## 翻訳できるもの

イベント会話・選択肢・スクロールテキスト・イベント名・マップ名・アクター（名前/ニックネーム/説明）・クラス・アイテム・武器・防具・スキル・状態・敵・コモンイベント・敵グループ・システム用語とメッセージ。

## 注意

- **中国語が□になる**：`Fonts\` のフォントに中国語の字形がない。中国語フォントに差し替え
- **0 件しか抽出されない**：テキストが RGSS スクリプト内、または `Game.rgss3a` / `.rgss2a` / `.rgssad` に梱包（先に展開が必要）
- **書き戻し後にエラー**：「バックアップ復元」で戻し、エラー内容を送ってください
- 書き戻しは文字列と長さプレフィックスだけを置換し、他のバイトは保持します
