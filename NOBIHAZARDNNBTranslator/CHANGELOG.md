## V1.4.0 — 2026-11-10

### 新增

- **数字签名**：exe 已带 Authenticode 签名（自签名证书，作者 JOSS），并附 `sign.ps1` 可重新签名
- 翻译引擎全部改为**免 Key**：微软翻译（默认）、MyMemory、Google 免费接口

### 变更

- 移除需要 Key / 需要自建服务的引擎（DeepL API、OpenAI 兼容、LibreTranslate）——不符合「像微软那样免 Key」的要求
- 实测结果：微软 ✅、MyMemory ✅（大陆直连，且比微软更保占位令牌）、Google ⚠️（需代理）、DeepL 网页接口已被官方版本门禁挡住、Yandex/Reverso 返回 403

## V1.2.0 — 2026-11-09

### 新增

- **支持 RPG Maker XP / VX / VX Ace**：直接读写 `.rxdata` / `.rvdata` / `.rvdata2`（Ruby Marshal 4.8）
- 提取范围与 MV/MZ 一致：对话、选项、滚动文本、说话人、事件名、地图名、角色/职业/物品/武器/防具/技能/状态/敌人/公共事件/敌群、系统菜单与提示、战斗消息
- 写回只替换字符串本身和它的长度前缀，其余字节原样保留；写完自动重新解析自检，失败就不落盘

### 修复

- 修正 Ruby Marshal 长整数解码：1..122 存的是「值 + 5」，之前按原值读，整体偏 5 字节，导致所有 RGSS 文件解析失败
- 修正字符串长度字段定位少算一个字节（会覆盖掉字符串类型标记）
- 修正识别 VX Ace / XP / VX 工程时因缺少 `js\plugins` 路径而崩溃
- 帮助菜单新增《XP / VX / VX Ace 使用说明》

## V1.0.0 — 2026-11-09

首个正式版本。

### 翻译范围

- **地图事件**：对话框（401）、滚动文本（405）、选项（102）、说话人（101）、改名/改昵称/改简介（320/324/325）
- **地图事件名字**：每条事件的名字也翻译，位置标注到「地图编号 · 事件编号 · 页码」
- **数据库**：物品、技能、武器、防具、角色、职业、状态、敌人 的**名字 + 介绍/说明/战斗消息**
- **公共事件**：名字 + 里面所有对话
- **敌群**：名字 + 战斗事件里的对话
- **设置 / 系统**：游戏标题、货币单位、菜单命令、参数名、系统消息（战斗提示、存档提示等）、属性/技能类型/武器类型/防具类型
- **地图**：地图显示名、地图列表里的名字
- **其他名字**：图块组名、动画名

### 翻译引擎

- **只保留微软翻译**（走 `cn.bing.com` 网页接口，免 Key、国内直连）
- 自动抓取会话令牌，20 分钟刷新，失败自动重抓
- 三级保护保证 `\C[2]`、`\N[1]` 这类控制符不丢失：令牌 → 换写法重试 → 分段翻译

### 界面

- 三个步骤分区：「① 选择游戏」「② 翻译设置」「③ 操作」，不再把所有控件堆在一起
- 表格拆成「序号 / 类型 / 原文 / 译文 / 位置 / 状态」六列，位置精确到「地图003 · 事件#12 · 第1页 · 对话」
- 状态栏实时显示「共 X 条 · 已译 Y · 待译 Z · 复核 W」
- 新增「测试引擎」按钮，批量翻译前先确认接口可用

### 修复

- 修复启动时偶发闪退（自制单尺寸图标导致的 GDI 句柄异常，已换成标准多尺寸 ICO）
- 修复微软翻译返回 404（旧免 Key 接口已下线）
- 修复 .NET Framework 默认只用 TLS 1.0 导致连不上必应
- 启动/崩溃日志：程序目录的 `startup.log`、`crash.log`
